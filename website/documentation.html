Getting started

Install the app for your platform from the Download page. On first launch, open Run (inference runtime drawer) to confirm either Ollama is reachable or llama.cpp binary is detected, then pick a model and press Start.

Inference runtime

Ollama

Select Ollama in the top bar, choose a tag from the list, and start. If a model is missing, the app can pull it into your local Ollama library (see Model library when Ollama is the active backend).

llama.cpp

Select llama.cpp, point to a .gguf file under your models directory (or download from the Hub into that folder), configure the llama-server binary if needed, then start.

Models & Hub

The Models drawer searches Hugging Face, shows curated recommendations, and splits installed vs available based on your active backend. With llama.cpp, installs are file downloads; with Ollama, matching entries use ollama pull against your configured API URL.

Knowledge & wiki

Ingest text, files, or conversations into the knowledge base. Compiled wiki pages support glossary blocks, cross-links, and a knowledge graph view. Chat can highlight wiki-derived phrases and link back to sources.

Training

The training panel launches a local Python LoRA workflow when configured. Keep model weights and datasets on disk paths the app can read; refer to project training/ scripts for CLI options and dependencies.

Privacy & data

Inference runs locally. No cloud API is required for core chat. Third-party services (e.g. Hugging Face downloads) are only used when you initiate them. Review the license for redistribution terms.
